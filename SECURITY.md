# Security Policy

## Supported Versions

Security fixes are provided for the latest released version of Realmwise.

| Version | Supported |
| --- | --- |
| 1.x | Yes |
| Versions before 1.0 | No |

## Reporting a Vulnerability

Please do **not** report security vulnerabilities through public GitHub issues, discussions, or pull requests.

Instead, report them privately through the repository’s **Report a vulnerability** link in the Security tab, or contact [maintainer contact method].

Include, where possible:

- A clear description of the issue and its potential impact.
- Steps to reproduce or a proof of concept.
- The affected Realmwise version and Windows version.
- Any suggested mitigation or fix.

Please avoid including personal data, access tokens, passwords, database files, cloud-sync bundles, or other sensitive information in your report.

## What to Expect

We will acknowledge receipt within 7 days and aim to provide an initial assessment within 14 days.

If the report is confirmed, we will work on a fix and coordinate disclosure with the reporter. We ask that you do not publicly disclose the issue until a fix or mitigation is available, unless we agree otherwise.

## Scope

Realmwise is a local-first desktop application. Security reports are welcome for issues involving the released application, its bundled dependencies, local data handling, OAuth/cloud-sync implementation, import/export handling, and update or release artifacts.

Third-party cloud services, user account security, and vulnerabilities in external providers should also be reported directly to the relevant provider.
