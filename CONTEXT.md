# Realmwise

Realmwise catalogs role-playing game books as shared works and individual owned copies.

## Language

**Work**:
A published RPG book whose descriptive metadata is shared by all owned copies.
_Avoid_: Copy, when referring to the published book

**Owned copy**:
A particular physical copy of a work in a collector's catalog, with its own condition and acquisition details.
_Avoid_: Work, when referring to the physical item

**Work candidate**:
A possible work returned by external lookup, before it is added to the catalog or used to refresh an existing work.
_Avoid_: Cataloged work
