# Domain docs

This repository uses a single-context layout: root `CONTEXT.md` and repository-wide ADRs in `docs/adr/`.

Before exploring a relevant area, read `CONTEXT.md` and any ADRs that affect it. If these files do not exist yet, proceed. The `/domain-modeling` skill creates them when terms or decisions are resolved.

Use the glossary's terms in issues, proposals, tests, and other output. If a needed concept is absent, reconsider the term or note the gap for `/domain-modeling`.

Surface any conflict with an existing ADR explicitly.
